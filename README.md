# 강호수첩

낭만강호(烟雨江湖) 임무의 미완·진행중·완료를 캐릭터별로 기록하는 반응형 웹앱입니다.

## 주요 기능

- 승인 임무 389개(기존225 + 신규164) 검색 및 공식 분류·지역·난이도·상태 필터
- 임무별 공식 명칭, 추천 등급, 전제조건, 선행임무, 준비물, 최종보상, 후속 정보 확인
- 캐릭터3명의 상태·한국 출시 동료30명 보유 설정을 각각 저장
- 목록과 상세의 체크를 누르면 미완 → 진행중 → 완료 → 미완으로 순환
- 버튼에 붙는 계층형 분류 드롭다운, 보유 동료 필터와 미보유 영입 임무 예외
- 기록 내보내기·가져오기
- PC 및 모바일 반응형 화면
- 나무위키 원문 연결

로그인과 별도 서버 없이 브라우저의 로컬 저장소를 사용합니다.

## 로컬 실행·검증

별도 설치·빌드 단계는 없습니다. 이 폴더에서 실행합니다.

```powershell
python -m http.server 4183 --bind 127.0.0.1
node --test
node --check app.js
node --check records.js
node --check browse.js
node --check navigation.js
```

현재 검토 주소: http://127.0.0.1:4183/?review=20261026
실제 운영 주소·origin은 바꾸지 않습니다. 로컬 화면의 기록은 운영 사이트 기록과 별개입니다.

## 기록 보호

- 저장 키 `gangho-notebook-v1`와 기존225개 ID를 유지합니다.
- 기존 `done` 배열은 유지하고 `doing`·`owned`를 추가합니다. 예전 완료는 클릭 전까지 완료입니다.
- 기록 로딩만으로 저장하지 않습니다. 손상 JSON·불완전 프로필·저장 오류가 나도 원본을 지우지 않습니다.
- 저장 실패 시 화면 모델을 되돌리고, 다른 창의 변경을 발견하면 덮어쓰지 않습니다.
- 버전1 백업 호환, 버전2 백업에 이름·선택 캐릭터·진행중·보유 동료·미등록 ID를 보존합니다.
- 역사적 별칭 `1.10-q19`도 폐기하지 않고, 원래 연결된 `1.10-q10`의 완료를 인식합니다.
- 실제 운영 브라우저의 기록으로 개발 시험하지 않습니다. `tests/legacy-backup.json`은 가상 자료입니다.

## 검색·모바일 탐색 보완 — 2026-10-26

- 검색어의 띄어쓰기와 Unicode 조합 차이를 정규화하고 실제 제목 일치 결과를 본문 언급보다 우선 표시합니다. 검색어가 없으면 원래 순서를 유지하며 선택한 필터는 초기화하지 않습니다.
- 모바일 상세는 브라우저 방문 기록 한 단계로 열립니다. 뒤로가기/`← 임무목록 돌아가기`는 목록으로, 앞으로가기는 상세로 복원합니다. 목록에서 다시 뒤로가면 이전 사이트로 정상 이동합니다.
- 상세에서 새 검색어를 입력하면 목록으로 복귀합니다. 재방문·새로고침 시 검색창과 결과가 어긋나지 않도록 화면 상태만 history에 보존하며 완료 기록 저장 구조는 바꾸지 않습니다.
- 돋보기는 나침반과 동일한 20px 영역·왼쪽 위치·세로 중심에 맞춥니다.
- 389개 임무의 노출 문구 3,580개 재점검. `설명가격` 4건, 명백한 오타와 조건/수량 주변 띄어쓰기 등 417필드 정리. 실제 수치·불확실성 주의는 유지하고 원본 자료는 수정하지 않았습니다.

## 보유 동료 필터 보완 — 2026-10-27

- `보유 동료 임무만` 체크는 상태 버튼 옆에 모든 분류에서 표시합니다. 체크 시 미보유 동료의 영입·지원·성장 임무를 모두 제외하고 다른 분류 임무는 유지합니다. 체크 해제 시 미보유 동료 임무도 다시 표시합니다.
- 헤더의 동료 아이콘과 기존 팝업을 유지하고 팝업에 현재 협객 이름과 `기준`을 표시합니다. 상단 협객 전환 후 팝업을 열면 해당 협객의 동료만 불러옵니다.
- 상태 버튼은 14px를 유지하며 모바일에서 고정 최소 너비를 풀고 상하4px·좌우9px·최소높이36px로 조정합니다. 모바일 문구는 `보유 동료만`이며 체크박스와10px 간격으로 한 줄에 표시합니다. PC 체크 영역에는 width:auto를 지정하여 기존 label 너비 규칙의 영향을 막습니다.
- 기본 체크이며 사용자가 해제한 선택은 캐릭터별로 저장·복원하고 백업에도 보존합니다. 검색·분류·상태 변경이나 이전 방문 기록이 이 선택을 덮어쓰지 않습니다.
- 기존 기록은 로딩 시 쓰지 않고, 완료·진행중·이름·동료 목록은 유지합니다. 모바일 분류·난이도·검색 입력/예시문구만 15px로 맞췄습니다.
- 모바일 완료율 게이지는 퍼센트 숫자와10px 간격을 두고 남은 너비를 채웁니다. PC 진행률은 유지합니다.
- 회귀 테스트44개 통과. 실제360px·390px 모바일과960px PC 배치 검토 후 사용자가 배포 승인했습니다. 기존 기본 스타일·말줄임·기록 저장 코드는 변경하지 않았습니다.
